# Saddle refinement baseline (test-only)

A repeatable baseline for **Python orchestration** of the default Fortran saddle refiner at upstream commit `5d866aeac756eafdb8d329e86077a5c2292fa309`. The controlled tests use neither numerical IRA registration, LAMMPS, pARTn, MPI workers, nor an interatomic potential. They do not establish native, cross-solver, or basin-physics parity.

### Controlled oracle

Use an installed pyKMC development environment with the IRA and pARTn Python interfaces importable. Configure them per the [project's installation instructions](../../README.md). Run from the repository root:

```sh
export PYTHONPATH="$PWD${PYTHONPATH:+:$PYTHONPATH}" OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1
MPI4PY_RC_INITIALIZE=0 python -m pytest -q tests/refinement \
    tests/recycle/test_carried_row_reconstruction.py tests/recycle/test_dedup_carried_rows.py
```

Expect 38 passed: 31 baseline cases and 7 existing recycling cases. The suite imports the Python interfaces but does not initialize MPI or run a native engine.

**Sensitivity checks (in memory, no source-file edits).** Replacing the saved-state `positions=self.states[row["state"]].system.positions.copy()` in `BasinsGenericEvents.refine_absorbing` with `positions=system.positions.copy()` fails both modes of `test_basin_selected_symmetry_own_minimum_and_rate`: spectator z is 5 Å rather than 6.25 Å in the energy query. Substituting direct `submit`/`submit_group` for the equivalent shorthand in ordinary refinement, basin exit refinement and endpoint reconstruction leaves all 31 controlled tests passing.

**Where to look at the pin.** `KMC.execute_refinements → Refinement.execute/refine_single → manager.partn_refine` is the ordinary path. `LammpsEngine.partn_refine` prepares the cell (or calls `partn_refine_AV`), disables final push and next-minimum movement, tests the displacement, and returns a total or difference. After rate construction and selection, `KMC._reconstruction_active_event → Reconstruction.reconstruct` pushes and minimizes toward both minima. `BasinsGenericEvents.execute` constructs states, refines absorbing edges and selects an exit; `system_from_state` is a **third geometry consumer**, not another saddle solver. In `KMC.run` the selected exit replaces the ordinary geometry, rate and time **only after** its own reconstruction succeeds; a failed basin result or failed exit reconstruction restores the ordinary event's endpoint/energy and leaves its waiting time intact.

**Inherited boundaries (not scientific acceptance criteria).**
- Basin full-cell submission omits types; the worker raises for a species-based freeze without types. The cropped path handles buffer/core remapping, but additional configured frozen atoms are turned into one-based *full-system* ids without a crop remap. No freeze validation, triclinic or mixed-alloy force-model support is inferred.
- Cropped ordinary saddle positions are wrapped by `System.update_positions`; cropped basin guesses are passed raw. Both payloads are observed; no claim they are numerically interchangeable.
- Multiple exit edges sharing a `(from_state, exit_state)` overwrite the stored saddle, while transition/energy retrieval can select the first row. Controlled fixtures use unique exit edges only. The radial threshold setting is guarded by search `push_mode` while refinement sets `r_push_mode`. Failed retries reapply the configured seed. Neither discrepancy is a recommendation to reproduce it in an alternative solver.
- The returned `ReconstructionOutput.saddle_positions` can alias system coordinates subsequently restored by `_reconstruction_active_event`. The control uses snapshots of the **actual two group requests**; use the saved refined local saddle plus its ids for the native comparison, not the aliased returned field.
- Native startup, collective cleanup, Fortran convergence, wrong-physics saddles, speed, and numerical equivalence under new solvers remain unverified. Scripted agreement is evidence about callers, **not** a Hessian index or mechanism certification.

### Scope of a separate native check

No native launcher, compiled dependency pins, or run artifacts are part of this baseline. For a separate before/after study, pin the actual installed LAMMPS, Fortran pARTn, IRA, and MPI build and use the same physical fixture and refinement mode on both sides. Do not compare full-cell with cropped energy references. Run one bounded failed solve and then a genuine accepted solve on the same local worker (at least two ranks), followed by both group endpoint minimizations. Check exact global atom IDs and neighbour order, the barrier against its proper minimum, reconstructed endpoints, BKL rate and time, and clean process exit. Separate actual worker reuse from solver retries. Whole-cell ordinary evidence cannot establish crop or basin behaviour. Separately review saved-state energy, unique basin edge, branch selection or fallback, and the local engine's atom registry before dispatching full-system coordinates to a previously cropped worker.
